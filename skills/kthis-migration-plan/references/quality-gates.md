# 验收门禁

> 收口前逐项过；自动化部分见 `scripts/audit-docs.sh`（`--strict` 时警告也算失败）。

## A. 自动检查（`audit-docs.sh`）

| # | 检查 | 通过标准 |
| --- | --- | --- |
| A1 | 册号连续 | 从 `00` 起连续、命名 `<NN>-名称.md` |
| A2 | 必要元素 | 每册有 H1、导航行、≥2 个二级标题 |
| A3 | 导航链 | 每册「上一册」= 前一册文件名 |
| A4 | 相对链接 | 全部可达（无失效 `](./x.md)`） |
| A5 | 占位符 | 无 `{{...}}` 残留 |
| A6 | 截图命名 | 匹配 `<NN>-<模块代号>-<英文名>.png` |
| A7 | 截图引用 | 每张被文档引用；文档引用的图都存在 |
| A8 | 单册篇幅 | 每册 ≤ `--max-lines`（默认 450 行），非空壳 |
| A9 | 跨册重复 | 同一句解释性内容不出现在 2 册以上（`--dup-strict` 时判定为失败） |

```sh
.agents/skills/kthis-migration-plan/scripts/audit-docs.sh --strict                 # 常规（跨册重复仅提示）
.agents/skills/kthis-migration-plan/scripts/audit-docs.sh --strict --dup-strict    # 收口前严格一遍
```

## B. 人工检查

| # | 项 | 通过标准 |
| --- | --- | --- |
| B1 | 索引同步 | README 索引表的册号/链接/说明与实际一致 |
| B2 | 单一维护 | 共用页签/共享分区只有一处正文，其余为引用 |
| B3 | 无 TODO | `<!-- TODO -->` 已清零或已在台账登记为「待源码复核」 |
| B4 | 命名一致 | 同一实体全文同名；码表用编码 |
| B5 | 界面差异 | 新增/编辑差异已写；未据「新增态截图」臆断页签不存在 |
| B6 | 来源可复核 | 关键行为标注了遗留来源路径 |
| B7 | 端点权威 | 接口以后端仓库的接口清单为权威，本册只写概要与缺口 |
| B8 | 编码 | 全文 UTF-8，无 GBK 乱码 |
| B9 | 覆盖完整 | 遗留界面单元（主页面/各页签/各弹窗）都有归属册 |
| B10 | 可执行性 | 每册能直接指导前后端实现（字段/控件/校验/事件齐备） |

## C. 收口动作

1. 跑 `audit-docs.sh --strict`，修到通过。
2. 更新 `_进度台账.md`：各册状态、修订记录、遗留 TODO 汇总。
3. `git add docs/migration/...` 提交（Conventional Commits，中文描述，如 `docs(migration): 新增 <模块名>迁移文档骨架与分册`）。
4. 若册序变动，复查 README 索引与跨册引用。

## D. 交付说明模板

```text
已完成《<模块>》迁移文档：共 N 册。
- 骨架：docs/migration/<NN>-<模块>/
- 台账：docs/migration/<NN>-<模块>/_进度台账.md（含待确认项）
- 校验：audit-docs.sh 通过（错误 0，警告 0）
待你确认：<≤3 个阻塞问题>
```
