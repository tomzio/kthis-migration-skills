# 验收门禁

> 收口前逐项过；自动化部分见 `scripts/audit-docs.sh`（`--strict` 时警告也算失败）。

## A. 自动检查（`audit-docs.sh`）

| # | 检查 | 通过标准 |
| --- | --- | --- |
| A1 | 册号连续 | 从 `00` 起连续、命名 `<NN>-名称.md` |
| A2 | 必要元素 | 每册有 H1、导航行、≥2 个二级标题 |
| A3 | 导航链 | 每册「上一册」= 前一册文件名 |
| A4 | 相对链接 | 全部可达（无失效的相对链接） |
| A5 | 占位符 | 无 `{{...}}` 残留 |
| A6 | 截图命名 | 匹配 `<NN>-<模块代号>-<英文名>.png` |
| A7 | 截图引用 | 每张被文档引用；文档引用的图都存在 |
| A8 | 单册篇幅 | 每册 ≤ `--max-lines`（默认 450 行），非空壳 |
| A9 | 跨册重复 | 同一句解释性内容不出现在 2 册以上（同时加 `--strict --dup-strict` 时判定为失败） |
| A10 | 系统参数总表 | 模块 `00-总览与通用约定.md` 存在「系统参数总表」；未使用参数时写「（无）」，不能为空 |

```sh
<技能目录>/scripts/audit-docs.sh --strict                 # 常规（跨册重复仅提示）
<技能目录>/scripts/audit-docs.sh --strict --dup-strict    # 收口前严格一遍
```

## B. 人工检查

| # | 项 | 通过标准 |
| --- | --- | --- |
| B1 | 索引同步 | README 索引表的册号/链接/说明与实际一致 |
| B2 | 单一维护 | 共用页签/共享分区只有一处正文，其余为引用 |
| B3 | 无 TODO | `<!-- TODO -->` 已清零或已在台账登记为「待源码复核」 |
| B4 | 命名一致 | 同一实体全文同名；码表用编码 |
| B5 | 界面差异 | 添加/编辑差异已写；未据「添加态截图」臆断页签不存在 |
| B6 | 来源可复核 | 关键行为标注了遗留来源路径 |
| B7 | 端点权威 | 接口以后端仓库的接口清单为权威，本册只写概要与缺口 |
| B8 | 编码 | 全文 UTF-8，无 GBK 乱码 |
| B9 | 覆盖完整 | 遗留界面单元（主页面/各页签/各弹窗）都有归属册 |
| B10 | 可执行性 | 每册能直接指导前后端实现（字段/控件/校验/事件齐备） |
| B11 | 页面类型与表单归属 | 先判定页面类型；不确定时已让用户选 A（维护 / 设置类列表页）或 B（默认页面形态），未自行假设。**A**：主页面册只含列表 + 查询条件 + 列表操作，无维护表单录入区 / 字段表 / 保存动作；维护表单单独成册（多页签 `shell` + `tab`，单表单 `dialog`）；查询条件表单未拆出；编码 / 描述 / 拼音码语义字段用一个 `Input.Search` 聚合搜索，未拆成多个输入框。**B**：表单可留页面主体，未强制拆弹窗 / 表单册，未造空主页面册（`doc-structure.md` §2 第 8 条） |
| B12 | 系统参数 | 模块 `00-总览与通用约定.md` 的「系统参数总表」列齐参数编码 / 名称 / 默认值 / 用途 / 取值点；未使用参数时写「（无）」，不得留空或 TODO |

## C. 收口动作

1. 跑 `audit-docs.sh --strict --dup-strict`，修到通过。
2. 更新 `_进度台账.md`：各册状态、修订记录、遗留 TODO 汇总。
3. 若册序变动，复查 README 索引与跨册引用。
