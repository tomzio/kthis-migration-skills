# 截图：自动识别、按功能命名、引用

> 截图目录：默认放共享根 `<迁移文档根>/images/`（`<前端>/docs/migration/images/`；`<前端>` = 路径配置的 `WEBHIS_FRONT_DIR`，见项目根 `.agents/paths.env`）；大模块也可放模块内 `<模块目录>/images/`（两种位置 `audit-docs.sh` 都认）。原则：截图只用于**核对标签与控件顺序**，完整功能以遗留源码为准。但**文件名必须能表达页面功能**，禁止保留 `截屏2026-…`、`image.png`、`IMG_1234`、中文名这类无意义名字。

## 命名规范（仓库约定）

```
<功能序号>-<目标模块代号>-<界面英文名>.<png|jpg|jpeg>
```

| 片段 | 取值 | 说明 |
| --- | --- | --- |
| 功能序号 | 两位数，如 `01` | 迁移分册批次（与迁移文档目录编号一致）。 |
| 目标模块代号 | 新侧模块码，如 `abc` | **用新侧代号**，不是遗留代号（新旧编码常不一致）。 |
| 界面英文名 | kebab-case 英文 | 见下表后缀 / 前缀约定。 |

英文名约定：主页面 / 编辑器 `-page`；页签 `-tab`；弹窗、对话框 `-dialog`；需要区分添加态时加前缀 `add-`（编辑态可省略或 `edit-`）。**文件名必须纯 ASCII**，截图里只有中文时翻译成英文 slug。

实例：`<NN>-<模块代号>-main-page.png`、`<NN>-<模块代号>-<英文名>-tab.png`、`<NN>-<模块代号>-add-<英文名>-tab.png`、`<NN>-<模块代号>-<英文名>-dialog.png`。

## 何时做

拿到或引用一张截图（尤其原始名形如 `截屏2026-10-12 09.47.32.png` / `image.png` / `Screenshot_…` / `IMG_1234.png` / 中文名）时：

**先识别 → 按页面功能改名 → 再引用**。不要带着无意义文件名往文档里写。

## 流程

1. **收集 + 审计**：`ls <迁移文档根>/images/`；或跑 `scripts/rename-screenshots.sh --audit <images-dir> <迁移文档根>` 列出「非规范命名 / 失效引用 / 未被引用」的图片。
2. **看图识别（关键步骤，必须模型亲自 `read` 图片）**：逐张用 read 打开图片，读出：
   - 业务域 / 模块；
   - 界面类型：主页面 · 列表 · 搜索弹窗 · 编辑弹窗 · 某弹窗内的**页签** · 独立辅助弹窗；
   - 界面标题与页签文案（截图中实际可见的）；
   - **添加态还是编辑态**；
   - 主要分区与关键控件（供 README 表「说明」列）。
3. **定名**：按规范组合三段；含糊时以**图中可见标题 / 页签文案**为准，并回 `<迁移文档根>/README.md`（模块索引 / 截图清单）与遗留源码核对归属，再定英文 slug。
4. **改名 + 同步引用**： `scripts/rename-screenshots.sh <images-dir> <迁移文档根> <旧名>=<新名> [更多…]` 脚本用 `git mv` 保历史，并自动把 `docs/` 下所有文档里的旧文件名（含 `images/`、`../images/` 两种写法）替换为新名。
5. **补引用**：在相关分册插入 `![<中文说明>](images/<新名>)` 与「对齐 `images/<新名>`」；更新 `README.md` 的**截图清单表**（链接 + 界面 + 说明）。
6. **门禁**：再跑一次 `--audit`，确认 无残留非规范名、无失效引用、无「未被任何文档引用」的图片。

## 识别要点 / 易错

- **态差异**：添加态弹窗常只显示主页签——别把「添加态截不到某页签」当成「没有该页签」（对照编辑态截图 / 源码）。
- **同壳多态**：同一外壳可能被多个界面复用，靠标题栏与顶部公共字段区分；必要时用 `add-` / `edit-` 区分态。
- **名实不同**：界面页签文案与文档标题可能不一致（界面文案 vs 源文标题）；**以界面可见文案为准**。
- 截图可能只截到部分内容；命名要反映**该截图所展示的界面**，而不是整个功能。
- 中文 → 英文 slug 时保留稳定术语：`tab`/`dialog`/`page`/`search`/`price`/`insurance`/`attribute`/`dosage-limit`/`fixed-asset` 等。

## 工具

```sh
# 审计：非规范命名 / 失效引用 / 未被引用
scripts/rename-screenshots.sh --audit <images-dir> [docs-dir]

# 改名 + 同步文档引用（可批量）；加 --dry-run 只打印不落盘
scripts/rename-screenshots.sh <images-dir> <docs-dir> <旧名>=<新名> [<旧名>=<新名> …]
```

脚本只做**机械改名与改引用**；「识别截图内容 → 定功能名」仍由模型看图完成。
