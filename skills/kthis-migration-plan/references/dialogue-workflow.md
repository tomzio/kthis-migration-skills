# 多轮协作流程与提问协议

> 迁移文档靠**反复迭代**成形。本文件规定每轮怎么推进、问什么、记什么。

## 0. 总纪律

- **一次只推进一段**：优先「一册一轮」，避免一次性甩出 20 册让用户无从审阅。
- **先确认再落地**：册划分、命名、范围先给方案等确认，再生成/填写。
- **问了就记**：每轮结论写进 `_进度台账.md`（已定 / 待定 / 阻塞）。
- **不许脑补**：能从遗留源码查证的自己查；查不到或涉及取舍的才问，且**≤3 个问题**。
- **改一处、扫全局**：用户新约束可能影响多册，要回填到所有受影响册并登记。

## 1. 轮次模板

### R0 · 定界（1 轮）

先读遗留源码与既有文档，再产出**范围卡**：

```text
模块（新侧代号）：<模块代号>（<模块名>）
遗留入口：<遗留 Editor / Page 标识或路径>
范围：主页面 + N 个编辑弹窗（各自若干页签）+ K 个辅助弹窗；不含 XXX
待确认：① 是否包含…？ ② 弹窗是否需要…？
```

问用户：**范围边界**、**模块代号**、**是否沿用某册的共用写法**。

### R1 · 册规划（1 轮，关键）

先报**档位**（轻量 / 标准 / 完整；判定见 `doc-structure.md` §2.1），再给出**册规划表**并**等确认**：

| 册号 | 册名           | 类型     | 说明                     |
| ---- | -------------- | -------- | ------------------------ |
| 00   | 总览与通用约定 | overview | —                        |
| 01   | 主页面         | main     | 含状态过滤/左树/结果列表 |
| 02   | <弹窗外壳册名> | shell    | 页签 03–07 挂载于此      |
| 03   | …页签          | tab      | …                        |

**只有确有内容的册才排**（轻量档 `00 + 01` 即可；`matrix` 只在确有跨界面共用内容时才排）。同时给出将要执行的 `scaffold-docs.sh` 命令行（册序即命令行的 `--volume` 顺序；轻量档可加 `--lite`），用户确认后执行。

### R2 · 搭骨架

执行 `scaffold-docs.sh` → 生成目录与空册 → 初始化 `_进度台账.md` → 把册表填进台账。

### R3+ · 逐册起草 / 修订（循环）

每册循环：

1. **读源码**：定位该界面单元的遗留实现，确认字段、校验、事件、码表、差异。
2. **填册**：按模板填写；不确定处 `<!-- TODO -->`。
3. **交付**：给出该册内容 + **本册待确认清单**（问题 + 我的建议）。
4. **收批注**：用户批注 → 修订 → 更新台账「修订记录」。
5. **标记**：本册状态置 `已确认` 或 `待源码复核`。

**提问话术示例**：

```text
《<NN> <册名>》草稿已出（N 行）。两点需你确认：
1) <某个存疑的联动 / 锁定规则>？（我倾向：<我的建议>）
2) <某字段是否另有独立含义>？（我暂记为：<我的记录>）
其余按遗留源码填写，未决处已标 TODO。
```

### Rn · 横向册

`数据流程与接口` / `共享分区与复用矩阵` / `迁移实施计划` 需**交叉校对**已定的分册：字段命名一致、共享内容归位、端点以后端 `02-接口.md` 为准。

### Rn · 索引与截图

更新 README 索引表与截图表。用户随时可能把截图丢进 `images/`，**收到截图就按「识别 → 改名 → 补引用」处理**。完整流程（审计 → 看图识别新增/编辑态 → 定名 → 改名 + 同步引用 → 补引用 → 复检）、命名规范与命令见 [screenshots.md](screenshots.md)。

### Rn · 收口

跑 `audit-docs.sh --strict`；清零错误与占位符；台账置为完成。

## 2. 进度台账格式（`_进度台账.md`）

见 `templates/_进度台账.md.tpl`：当前状态 / 册规划与进度 / 待确认问题（阻塞项）/ 修订记录 / 遗留 TODO 汇总。

**每轮结束必须更新**：进度表状态、修订记录一行、新增/关闭的待确认项。

## 3. 何时用 `new-volume.sh`

- 发现**漏了一个页签/弹窗**要在中间插入 → `--at N`。
- 插入点之后的所有册会被**自动重排册号 + 重写导航 + 重写 `NN-册名.md` 引用**。
- `--dry-run` 只打印将做的改动，不落盘；之后**人工核对 README 索引表的「册」号列**（脚本只改链接，不改表格里的数字单元格）。

## 4. 冲突处理

| 冲突             | 处理                                                   |
| ---------------- | ------------------------------------------------------ |
| 截图 vs 源码     | **以源码为准**，册内注明差异                           |
| 文档之间         | 找权威册（通用约定 / 复用矩阵 / 后端接口），他册改引用 |
| 用户口径 vs 源码 | 以用户业务意图为准，但要求确认为**有意变更**并登记     |
