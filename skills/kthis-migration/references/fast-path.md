# 快速路径与准确性红线

> 迁移耗时的**大头不是"多读一遍规范"**，而是三类开销：重复读同一批文件、验证回路太长（起服务 / 导航 / 截图 / 改 / 再跑）、串行等待。本文件规定哪些提速**允许**、哪些**禁止**、每项提速要带什么门禁。
>
> **总原则**：准确性的关键是「**有没有可判定的验收点**」，不是「读得多不多」。
> - 能自动判定的（lint / tsc / grep / 数值核对）→ 快慢不影响准确性，随便提速。
> - 需要人 / 模型判断的（布局像不像、行为一致不一致）→ **次数不能减，只能提效率**（一键截图、并排比对、速查卡）。

## 1. 允许提速（零风险，行为完全等价）

- **dev server 全程只起一次**：`yarn dev` 起一次靠热更新，不要每改一次重启（rspack 冷启动 + 首次编译很贵）。
- **lint / tsc 放到阶段收尾跑**，不必每次小改都跑；跑了结论一样。
- **遗留源码一次性转码**：先把本模块要看的文件批量 `iconv -f GB18030 -t UTF-8` 到临时目录，之后用检索工具秒级查 —— 不要每个文件现场转码。
- **e2e 串成一条命令**：确保服务在跑 → 登录 → 导航到路由 → 元素级截图 → 顺带收集 console / network 错误（见 [e2e-verification.md](e2e-verification.md)），把 5 步合成 1 步。
- **复用既有目录骨架**：`src/pages/<mod>/` 下同类「主页面 + 多 Tab 编辑弹窗」可直接复制结构再改字段（见 repos-and-map「已落地样例」）。
- **遗留追踪并行**：不同界面 / 不同链路可由多个子代理各追一条。

## 2. 允许提速（低风险，**必须带门禁**）

- **速查卡替代通读长册**：布局规范的「落地前自查清单」（frontend-porting §10）就是速查卡 —— 只放**可判定的数值**，它是**检查表而非替代品**；遇到清单覆盖不到的情况，回去读整册（`00-前端布局规范.md`）。
- **批量确认**：册规划一次性给全；界面实现**一批一批**确认，不再一册一轮。门禁：逐条列出待确认项并写进 `_进度台账.md`，用户仍可逐条驳回。
- **并行实现多个界面**：门禁 —— 边界是**不同目录、不同文件**；**共享组件与公共样式的改动禁止并行**；并行结束后**统一做一次集成 e2e**（不是各做各的就算完）。

## 3. 禁止精简（准确性红线）

- **遗留端到端走通不能省**（SWT 视图 → action / `I*Service` → server impl → iBATIS map → 表）。它是业务逻辑真源，只能并行、批量，**不能跳**。
- **「与遗留行为比对」不能省**：新侧同场景逐项比对（见 [backend-verification.md](backend-verification.md) §4），差异必须判定为「有意的等价替换」还是「实现错误」。
- **e2e 视觉核验不能减次数**：只是把次数**摊到过程中**（每完成一个界面立刻按 §10 自查 + 元素级截图比对），而不是攒到最后一次性做；攒到最后等于放大返工。
- **共享内容必须单一来源**：共用页签 / 共享分区 / 模块级约定只写一处（`00-总览与通用约定.md` 或「共享分区与复用矩阵」册），其余引用 —— 提速不能靠复制。

## 4. 可选的「免文档」快速通道（有严格前提）

**适用判据（全部满足才可开）**：

- 界面单元**单一**（没有多弹窗共用、没有跨界面共享分区）；
- 字段少、无复杂联动与保存流程（无主从 / 无编码生成 / 无多步事务）；
- 后端端点**已存在**且已被前端用过（无需添加接口）；
- 有对应的**遗留界面可现场跑通**、或已有同类界面可对照。

**开这条路时仍必须做**：

- 先读 UI 规则（`.agents/rules/*` + 迁移文档的 `00-前端布局规范.md`）；
- 实现后补一份**最小设计记录**（`_进度台账.md` 记：范围、遗留入口、字段来源、差异点），供后人核对；
- 做「与遗留行为比对」+ §10 自查 + 元素级截图核验。

**不得开这条路**：多页签 / 多弹窗共用、有保存或事务流程、需添加后端接口、涉及主数据/编码规则/权限差异。

## 5. 一张图记住

```text
能自动判定的  →  随便提速（lint / tsc / grep / 数值核对）
要人眼判定的  →  次数不减，只提效率（一键截图 + 并排比对）
业务真源      →  不能省（遗留走通、同场景比对）
```
